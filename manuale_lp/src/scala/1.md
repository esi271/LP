# Overview
Scala è un linguaggio che unisce la programmazione funzionale con la programmazione OOP.
I punti di vendita di Scala sono:
- sintassi succinta, elegante e flessibile
- interprete interattivo
- supporto per linguaggi DSL

Inoltre Scala è staticamente tipato.

## Primo assaggio di Scala
```Scala
class Upper {
    def upper(strings: String*): Seq[String] = {
        strings.map((s:String) => s.toUpperCase())
    }
}
val up = new Upper
Console.println(up.upper("A", "First", "Scala", "Program"))

```

Questo snippet di codice non si puo' compilare con `scalac` ma è possibile eseguirlo nel REPL di scala
con `scala nomefile.scala` o `:load nomefile.scala`.

Possiamo semplificare il nostro script in questo modo:
```Scala
object Upper {
    def upper(strings: String*) = strings.map(_.toUpperCase())
}
println(Upper.upper("A", "First", "Scala", "Program"))
```

La keyword `object` indica una classe a istanza singola. Non esistono metodi statici ma **metodi di oggetti singleton**.

Abbiamo semplificato `(s:String) => s.toUpperCase()` in `_.toUpperCase()`. `map` ha un solo argomento quindi usiamo il carattere
wildcard `_` che si comporta
come una variabile anonima a cui assegnamo la stringa passata prima che `toUpperCase` venga chiamato.

Possiamo fare un ultimo refactor in modo da poterlo poi compilare.

```Scala
object Upper { 
    def main(args: Array[String]) = {
        args.map(_.toUpperCase()).foreach(printf("%s ",_)) 
        println("") 
    } 
}
```

## Mutabilità delle variabili
Possiamo decidere se avere una variabile mutabile o immutabile tramite le keyword `var` e `val`.

## List comprehension
Similmente ad Erlang abbiamo anche qui le list comprehension più comunemente chiamate `for` comprehension in Scala.

`def sum_evens = (L:List[Int]) => {var sum=0; for (X <- L if X%2 == 0) sum += X; sum}`

estraiamo gli elementi `X` della lista `L` e se sono pari li sommiamo alla variabile `sum`.
### Yielding
Creare nuove collezioni con le for comprehension
```Scala
val is_prime = (X:Int) => {
    val divisors = (X:Int) =>
        for { Y <- List.range(2,math.sqrt(X).toInt) if (X % Y == 0)} yield Y
    divisors(X).length == 0
}
```

In questo caso aggiugiamo il valore `Y` nella lista `divisors` per ogni iterazione del `for`

## Operatori
Gli operatori in scala **sono tutti metodi** 

`1 + 2`

Questa espressione è vista come `1 .+(2)`. Quando un metodo ha un solo argomento possiamo togliere sia il punto che le parentesi.
Possiamo chiamare i metodi anche con caratteri non alfanumerici con qualche eccezione, 
i caratteri parentesi `(,),[,],{,}` e separatori --- \`, ', ", ., ; e ,.

## Pattern matching
Il pattern matching è uguale a OCaml ma con sintassi diversa

esempio match semplice:
```Scala
val bools = List(true, false)  
    for (bool <- bools) { 
        bool match { 
            case true => println("heads") 
            case false => println("tails") 
            case _ => println("something other than heads or tails (yikes!)") 
        } 
}
```

esempio match su tipo:
```Scala
val sundries = List(23, "Hello", 8.5, 'q')
for (sundry <- sundries) {
  sundry match {
    case i: Int      => println("got an Integer: " + i)
    case s: String   => println("got a String: " + s)
    case f: Double   => println("got a Double: " + f)
    case other       => println("got something else: " + other)
  }
}
```

matching sulle sequenze:
```Scala
val willWork    = List(1, 3, 23, 90)
val willNotWork = List(4, 18, 52)
val empty       = List()

for (l <- List(willWork, willNotWork, empty)) {
  l match {
    case List(_, 3, _, _) => println("Four elements, with the 2nd being '3'.")
    case List(_*)         => println("Any other list with 0 or more elements.")
  }
}
```

matching sulle liste 2:
```Scala
val willWork    = List(1, 3, 23, 90)
val willNotWork = List(4, 18, 52)
val empty       = List()

def processList(l: List[Any]): Unit = l match {
  case head :: tail =>
    format("%s ", head)
    processList(tail)
  case Nil => println("")
}

for (l <- List(willWork, willNotWork, empty)) {
  print("List: ")
  processList(l)
}
```
