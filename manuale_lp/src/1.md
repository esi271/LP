# Introduzione e Tipi Primitivi


## OCaml
Ocaml viene reso disponibile con:

- compilatore

    ``` bash
    ocamlc -o <nome> <nome>.ml
    nome
    ```

- interprete

    ``` bash
    rlwrap ocaml
    ```


## Tipi numerici 

### Integers

``` ocaml
let i = 42;;
```

#### Operatori:

|Operatore| `+` | `-`| `*` | `/` | `mod`|
|:--|:--|:--|:--|:--|:--|
|Significato| somma | differenza| prodotto| divisione| resto|

#### Conversioni `int` $\to$

- `float` : `float_of_int n`

    ```
    # float_of_int 3;;
    - : float = 3.
    ```


- `string` : `string_of_int n`

    ```
    # string_of_int 42;;
    - : string = "42"
    ```

- `char` : `Char.chr n`

    ```
    # Char.chr 65;;
    - : char = 'A'
    ```


### Float

``` ocaml
let f = 42.0;;
```

#### Operatori:

|Operatore| `+.` | `-.`| `*.` | `/.` |
|----|-----|----|-----|-----|
|Significato| somma | differenza| prodotto| divisione|

#### Conversioni `float` $\to$

- `int` : `int_of_float f`

    ```
    # int_of_float 3.7;;
    - : int = 3
    ```

- `string` : `string_of_float f`

    ```
    # string_of_float 3.5;;
    - : string = "3.5"
    ```


## Booleans

``` ocaml
let b = true;;
```

### Operatori:

| Operatore | Significato |
|-----------|-------------|
| `&&`      | and logico |
| `` || ``  | or logico |
| `not`     | negazione |
| `=`       | uguaglianza strutturale |
| `<>`      | disuguaglianza strutturale |
| `==`      | uguaglianza fisica |
| `!=`      | disuguaglianza fisica |

``` ocaml
let s = "ciao";;
s = "ciao";; (* -> true*)

let s = "ciao";;
s == "ciao";; (* -> false*)
```

### Conversioni `bool` $\to$

- `string` : `string_of_bool b`

    ```
    # string_of_bool true;;
    - : string = "true"
    ```

- `int` : `Bool.to_int b`

    ```
    # Bool.to_int true;;
    - : int = 1
    ```

- `float` : `Bool.to_float b`

    ```
    # Bool.to_float false;;
    - : float = 0.
    ```


## Characters

``` ocaml
let c = 'a';;
```

Operatori: valgono gli operatori matematici.

### Conversioni `char` $\to$

- `int` : `Char.code c`

    ```
    # Char.code 'A';;
    - : int = 65
    ```

- `string` : `String.make 1 c`

    ```
    # String.make 1 'A';;
    - : string = "A"
    ```


## Strings

Le stringe sono **immutabili**.

``` ocaml
let s = "abc";;
```

### Operatori:

|Operatore| `^` | `.[]`|
|----|-----|----|
|Significato|Concatenazione| Accesso posizionale |

### Modulo `String`

|Operatore| `length s` | `is_empty s`| `includes affix s`| `contains s c`|
|----|----|----|----|----|
|Significato| Lunghezza di s| Restituisce se `s` è la stringa vuota| Restituisce se `s` include la stringa `affix`| Restituisce se `s` contiene il carattere `c`|

### Conversioni `string` $\to$

- `int` : `int_of_string s`

    ```
    # int_of_string "42";;
    - : int = 42
    ```

- `float` : `float_of_string s`

    ```
    # float_of_string "3.5";;
    - : float = 3.5
    ```

- `bool` : `bool_of_string s`

    ```
    # bool_of_string "true";;
    - : bool = true
    ```


- `bytes` : `Bytes.of_string s`

    ```
    # Bytes.of_string "abc";;
    - : bytes = Bytes.of_string "abc"
    ```

L'alternativa mutabile delle stringhe sono i `bytes`.


## Bytes

Sono **mutabili**

``` ocaml
let b = Bytes.of_string "abc";;
```

### Operatori

|Operatore| `Bytes.set b p c` | `Bytes.to_string`|
|----|-----|----|
|Significato|Mette `c` alla posizione `p` di `b`| Restituisce la stringa di `b` |

### Conversioni `bytes` $\to$

- `string` : `Bytes.to_string b`

    ```
    # Bytes.to_string (Bytes.of_string "abc");;
    - : string = "abc"
    ```
