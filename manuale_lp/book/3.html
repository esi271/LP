Manuale Linguaggi di Programmazione

Collezioni e tipi definiti dall’utente

Collezioni

Liste

let l = [e1; e2; e3; ...; en];;

Sono:

  • Omogenee.
  • immutabili: quando sembra che modifichiamo una lista, magari con l’operatore cons, in realtà ne stiamo creando una nuova.
  • Acesso sequenziale.

Operatori

Tra gli operatori di base abbiamo:

  • cons ::

    Indica la concatenazione tra un elemento e una lista: e :: l.

    e :: [e1; e2; e3];; (*-> [e; e1; e2; e3*)

    Può essere usato per fare pattern matching strutturale della lista:

    match l with
    | hd :: tl ->...;
    | [] -> ...

  • concatenazione @

    Concatena due liste:

    [e1; e2] @ [e3; e4];; (*[e1; e2; e2; e4]*)

    È un operatore inefficiente, per questo motivo è preferibile usare cons

Modulo List

Tuple

Sono liste eterogenee di lunghezza fissa:

let a_tuple = (5, 'a', "a string");;

È possibile accedere agli elementi tramite pattern matching strutturale:

match a_tuple with
    | (e1, e2, e3) -> ...
    | _ -> ...

Le coppie

Quando definisco una coppia:

let a_pair = (1, "w");;

Posso usare i metodi:

  • fst a_pair: accedo al primo elemento.
  • snd a_pair: accedo al secondo elemento.

Array

Gli array sono liste ad accesso diretto tramite posizione, inoltre sono:

  • omogenee
  • mutabili
let an_array = [|1;2;3|];;

Operatori

Modulo Array

  • Array.make n e: crea un array di \(n\) elementi con tutti gli elementi uguali a e.
  • Array.concat [an_array_1; an_array_2]: restituisce l’array ottenunto concatenando i due array.
  • Array.make_matrix n m e: crea una matrice \(n \times m\) con elementi e.

Record

I record sono:

  • accessibili per nome (tramite i nomi dei campi) con la dot-notation
  • eterogenei
  • mutabili tramite la keyword mutable : sono tuple con queste proprietà.
type person = {name: string; mutable age: int};;
let r = {name = "Walter"; age = 35};;

Tipi definiti dall’utente

Alias

È il modo più semplice per definire un nuovo tipo: consiste nel dare un nuovo nome a un tipo esistente.
Qualsiasi tipo può essere “aliasato”.

type int_pair = int*int;;
let a : int_pair = (1,3);;

Varianti

Un tipo variante elenca tutte le possibili forme dei valori di quel tipo.
Ogni caso è identificato da un nome che inizia con la maiuscola, chiamato costruttore.

type variant =
    | Nothing
    | Integer of int
    | Record of {name : string; mutable age : int};;

Questi costruttori personalizzati sono usabili nel pattern matching strutturale, eventualmente ignorando le informazioni che non mi servono:

match variant with
    | Nothing -> ...
    | Integer _ -> ... (*qua non mi serve sapere il contenuto*)
    | Record {name = n; age = a} -> ...

Tipi mutualmente ricorsivi

Un tipo mutualmente ricorsivo deve essere dichiarato tramite la keyword and, così che tutti i nomi siano visibili contemporaneamente in tutte le definizioni:

type card = Card of regular | Joker
    and regular = { suit : card_suit; name : card_name; }
    and card_suit = Heart | Club | Spade | Diamond
    and card_name = Ace | King | Queen | Jack | Simple of int;;
